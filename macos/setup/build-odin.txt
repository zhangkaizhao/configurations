# Odin

2026-06-22

version: dev-2026-06

Reference: https://odin-lang.org/docs/install/

> Install clang and LLVM (the versions we support are 14, 17, 18, 19, 20, and 21) using your package manager

Tested: clang and LLVM version 22 is supported. 

Install it:

```
sudo port install llvm-22
sudo port select --set llvm mp-llvm-22
```

Build:

```
make release-native
cd vendor/
../misc/remove_libraries_for_other_platforms.sh
cd ..
mkdir /opt/programs/odin
cp -r LICENSE base core examples odin shared vendor /opt/programs/odin/
```

No need to make a soft link for `libLLVM.dylib` already:

```
sudo rm -f /usr/local/lib/libLLVM.dylib
```

Clean all before update:

```
rm -r /opt/programs/odin/*
```
